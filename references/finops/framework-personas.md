# FinOps Framework — Personas (1차 출처 요약)

> 출처: FinOps Foundation — <https://www.finops.org/framework/personas/> (curl 수집: 2026-06-09)  
> 본 문서는 공식 페이지에서 finops-lab 교재 인용에 필요한 핵심만 추출·정리한 요약본임.

## 핵심 정의
FinOps Persona(페르소나)는 클라우드를 사용·추적·관리·지휘하는 데 관여하는 역할 유형을 의미하며, 하나의 페르소나가  
다양한 관련 직무·직책의 여러 사람을 대표할 수 있음("may represent many people in a variety of related roles or job titles").  
매우 작은 조직에서는 한 사람이 여러 FinOps 페르소나의 업무를 동시에 수행할 수 있음.  
공식 페이지는 페르소나를 **Core Personas**(핵심)와 **Allied Personas**(연계)로 구분하며,  
각 페르소나는 조직과 FinOps 실천에서 고유한 관점·과제·지표·추구 성과(perspectives, challenges, metrics and outcomes)를 가짐.

## 공식 구성 항목 (영문 명칭 그대로)
### Core Personas (6종 — 페이지에 명시적 섹션으로 제시)
- **FinOps Practitioner**
- **Leadership**
- **Product**
- **Engineering**
- **Finance**
- **Procurement**

핵심 정렬 문장: "These Core Personas provide all of the organizational disciplines to successfully use cloud effectively."  
(핵심 페르소나가 클라우드를 효과적으로 사용하기 위한 모든 조직적 분야 역량을 제공함)

### Allied Personas (연계 분야 — "including" 표현, 닫힌 5개 집합이 아닌 명시적 예시)
- **Sustainability**
- **ITAM**
- **ITFM/TBM**
- **Security**
- **ITSM/ITIL**

특징: Allied Personas는 FinOps 실천에 직접 관여하지 않으나(전통/신흥 분야), FinOps Practitioner와 협업이 필요할 수 있으며,  
이들의 역할은 Framework Capability인 **"Intersecting Disciplines"** 와 정렬됨(활동이 교차하는 지점을 규정).

## 교재 인용 포인트
1. FinOps 페르소나를 "사람"이 아닌 "역할 유형"으로 정의 — HBT 멤버를 Core 6 페르소나에 매핑할 때 1:1이 아닌 다대다 가능함을 명시.  
2. Core Personas 6종(FinOps Practitioner / Leadership / Product / Engineering / Finance / Procurement)을 교재 표준 명칭으로 고정 사용.  
3. Allied Personas(Sustainability·ITAM·ITFM/TBM·Security·ITSM/ITIL)는 "including" 예시이므로 "대표적 연계 분야"로 인용하고 폐쇄 목록으로 단정하지 않음.  
4. Allied ↔ "Intersecting Disciplines" Framework Capability 연결을 교차 분야 거버넌스 설명의 1차 출처 근거로 활용.  
5. 소규모 조직에서 1인이 다수 페르소나를 겸임할 수 있다는 원문을 HBT 조직 규모별 운영 모델 설계 근거로 인용.
