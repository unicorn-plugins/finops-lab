# 유닛 2. FinOps란 무엇인가

> 원본: [What is FinOps?](https://learn.microsoft.com/en-us/training/modules/get-started-with-finops/2-what-is-finops) · 약 2분

## 개요

**FinOps Foundation**은 FinOps를 다음과 같이 정의함:

> "클라우드의 비즈니스 가치를 극대화하고, 적시의 데이터 기반 의사결정을 가능하게 하며,  
> 엔지니어링·재무·비즈니스 팀 간 협업을 통해 재무적 책임을 창출하는  
> **운영 프레임워크이자 문화적 실천(operational framework and cultural practice)**"

FinOps는 조직 내 문화적 전환을 지원하며, 효율성 제고와 클라우드 투자의 효과적 관리를 지향하는  
모범사례를 촉진함. 책임성과 데이터 기반 의사결정을 장려하여 비즈니스 성장을 뒷받침함.

### 흔한 오해: FinOps = 단순 비용 절감?

통념과 달리 FinOps의 1차 목적은 단순 비용 최적화를 넘어섬.  
FinOps는 클라우드 재무를 종합적으로 관리하는 접근으로, 클라우드 지출 최적화와 더불어  
**운영 효율성·자원 활용도·전반적 비즈니스 민첩성** 향상에 초점을 둠.

FinOps 원칙을 수용함으로써 조직은 단지 비용 통제에 그치지 않고:

- 클라우드 투자를 전략 목표와 정렬(align)
- 혁신(innovation) 추동
- 클라우드 관리 관행의 지속적 개선 촉진

을 함께 달성하고자 함.

## FinOps 프레임워크

FinOps 프레임워크는 FinOps 실천을 확립하고 고도화하기 위한 **운영 모델(operating model)**을 제공함.  
조직이 클라우드의 비즈니스 가치를 극대화하고, 적시의 데이터 기반 의사결정을 가능하게 하며,  
엔지니어링·재무·비즈니스 팀 간 협업으로 재무적 책임을 창출하도록 도움. 요컨대 **프레임워크는 FinOps의 운영 모델**임.

프레임워크는 FinOps 실천의 **빌딩 블록(building blocks)**으로 비유 가능.  
실무자는 블록을 다양한 방식으로 선택·배치 가능하며, 동일한 구성요소로부터  
각기 고유한 FinOps 구현을 만들어 냄.

FinOps와 마찬가지로 프레임워크 자체도 커뮤니티의 경험·기여·논의를 통해 지속 진화하며,  
성공 사례를 담은 스토리·페이퍼·플레이북 라이브러리가 계속 확장되고 있음.

### 프레임워크의 1차 구성요소

1. **원칙(Principles)**
2. **페르소나(Personas)**
3. **단계(Phases)**
4. **성숙도 모델(Maturity model)**
5. **도메인(Domains)**
6. **역량(Capabilities)**

> 📎 자세한 내용은 FinOps Foundation의 FinOps Framework 참조.
