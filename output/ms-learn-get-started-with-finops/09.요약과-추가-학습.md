## 요약

FinOps는 클라우드의 비즈니스 가치를 극대화하고, 적시의 데이터 기반 의사결정을 가능하게 하며,  
엔지니어링·재무·비즈니스 팀 간 협업을 통해 재무적 책임을 창출하는 **운영 프레임워크이자 문화적 실천**임.  
빠르게 진화하는 디지털 환경에서 클라우드 서비스는 비즈니스 운영에 필수적이 되었으나 동시에  
상당한 비용 원천이 될 수 있음. FinOps는 조직적·문화적 전환을 촉진하여 클라우드 투자에서  
최대 가치를 끌어내도록 돕는 구조적 접근으로 이 과제를 다룸.

FinOps의 핵심에는 **6대 원칙**이 있으며, 개인·팀이 자기 클라우드 지출에 오너십을 갖도록 하면서  
교차 기능 협력 문화를 조성함. FinOps 프레임워크의 핵심 구성요소는 다음과 같음:

- **원칙(Principles)** · **단계(Phases)** · **성숙도 모델(Maturity model)**
- **페르소나(Personas)** · **도메인(Domains)** · **역량(Capabilities)**

---

## 핵심 정리 (한눈에)

| 구성요소 | 핵심 내용 |
|---|---|
| 비용 모델 | CapEx(온프레미스 선투자) → OpEx(클라우드 사용량 과금) 전환 |
| 정의 | 비용 절감을 넘어 **비즈니스 가치 극대화** + 협업 + 재무 책임 |
| 6대 원칙 | 중앙팀 주도 · 협업 · 적시 데이터 · 오너십 · 비즈니스 가치 · 가변비용 활용 |
| 단계 | Inform → Optimize → Operate (반복 루프, 순서 비강제) |
| 성숙도 | Crawl → Walk → Run (모두가 Run일 필요는 없음) |
| 페르소나 | 핵심 6종(실무자·리더십·제품·엔지니어링·재무·조달) + 연계 5종 |
| 도메인 | 사용·비용 이해 / 가치 정량화 / 사용·비용 최적화 / 실천 관리 |
