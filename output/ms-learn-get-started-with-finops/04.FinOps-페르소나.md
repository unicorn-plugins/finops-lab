# 유닛 4. FinOps 페르소나

> 원본: [FinOps Personas](https://learn.microsoft.com/en-us/training/modules/get-started-with-finops/4-finops-personas) · 약 2분

---

FinOps를 성공적으로 도입하려면 조직 내 다양한 이해관계자와 협력해야 함.  
이 과정에서 FinOps 실천에 기여할 사람을 먼저 식별하고, 각자의 목표·동기를 이해하는 것이 중요함.

---

## 핵심 페르소나 (Core Personas)

| 페르소나 | 1차 목표 |
|---|---|
| **FinOps 실무자(Practitioner)** | 교육·표준화·문화적 성장과 지원을 통해 조직에 모범사례를 정착시킴 |
| **리더십(Leadership)** | 클라우드 투자가 비즈니스 목표와 정렬되어 있다는 확신 확보 |
| **제품(Product)** | 정확한 가격 책정과 함께 신규 제품·기능을 신속히 시장 출시 |
| **엔지니어링(Engineering)** | 일상 업무를 유지하면서 더 빠르고 고품질의 서비스를 조직에 제공 |
| **재무(Finance)** | 클라우드 비용을 정확히 예산화·예측·보고 |
| **조달(Procurement)** | 클라우드 플랫폼 관계(벤더) 관리 |

---

## 연계 페르소나 (Allied Personas)

FinOps 실무자와 협력하여 클라우드 비용 관리 우선순위와 균형을 맞추는 인접 직능:

| 페르소나 | 개요 |
|---|---|
| **ITSM / ITIL** | IT 서비스 관리·IT 인프라 라이브러리. IT 서비스 운영을 표준화·간소화하고 서비스 품질·신뢰성을 높이며, 합의된 서비스 수준 충족과 성능 목표를 클라우드 비용 관리 우선순위와 균형 |
| **ITAM** | IT 자산 관리. 양측 전문성·데이터를 활용해 IT 자산 관리의 효율성·투명성·가치를 달성하고, 비용 최적화·규정 준수·전략 목표 지원을 비용 관리 우선순위와 균형 |
| **지속가능성(Sustainability)** | 클라우드 사용이 환경 영향을 최적화하도록 보장하고, 책임성을 견인하며, 광범위한 지속가능성 목표 진전을 비용 관리 우선순위와 균형 |
| **보안(Security)** | FinOps 전문성·인사이트를 활용해 클라우드 보안 지출을 최적화하고, IT 보안 재무 거버넌스를 개선하며, 조직 전반의 클라우드 보안 태세를 강화 |
| **ITFM / TBM** | IT 재무 관리·기술 비즈니스 관리. IT 지출의 투명성을 제공하고 정보 기반 의사결정을 가능하게 하여, 클라우드·전통 IT 투자가 비즈니스 우선순위와 정렬되고 비용 효율적이며 측정 가능한 가치를 제공하도록 보장 |

> 📎 자세한 내용은 FinOps Foundation의 FinOps Personas 참조.
