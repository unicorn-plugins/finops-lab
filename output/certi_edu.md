# FinOps 강의 신뢰도 제고를 위한 자격증·공인 교육 추천서

> 대상: KT 직원 대상 **Azure 기반 FinOps 실무(1일 과정)** 강의 강사  
> 목적: 강의 신뢰도 제고를 위한 공신력 있는 자격증 취득 또는 공인 교육 수료  
> 작성: finops 팀 (전략기획 태희 · 약정전략 커밋터 조사 / 오케스트레이터 클로니 취합)  
> 작성일: 2026-06-29

---

## 1. 핵심 결론 (TL;DR)

- FinOps 분야의 **유일한 국제 표준 발급기관**은 **FinOps Foundation**(Linux Foundation 산하 비영리)임.  
  강사 개인이 취득 가능한 1차 공신력 자격증은 사실상 FinOps Foundation 라인업으로 한정됨.
- **Microsoft 단독 "FinOps 자격증"은 존재하지 않음.**  
  MS가 제공하는 것은 ① Microsoft Learn **수료 배지**(시험 자격증 아님), ② Azure 인증(AZ-104/AZ-305)의 비용·거버넌스 보완재,  
  ③ 실습 콘텐츠 출처인 **FinOps Toolkit** 공식 문서임. MS는 조직 단위 **FinOps Certified Service Provider** 인증을 보유(2025-06).  
  (단, 제품 Cost Management의 `FinOps Certified Platform` 인증 여부는 공개 페이지에서 미확인 — 단정 불가)
- **권장 강사 자격 스택**: `FinOps Foundation FOCP`(필수) + `Microsoft Learn FinOps 배지 2종`(무료·즉시) + `AZ-104 또는 AZ-305`(Azure 실무 증명, 선택).

## 3. FinOps Foundation 자격증 (강사 개인 취득 대상)

FinOps 분야 유일의 벤더 중립 국제 표준 인증. 발급기관 독립성·국제 인지도·갱신 체계를 모두 충족함.

| 자격증 | 대상 | 시험 형식 | 응시료(USD) | 갱신 | 사전요건 |
|---|---|---|---|---|---|
| **FOCP** (Practitioner) | 입문~실무자, 강사 | 객관식 50문항 / 60분 / 75% 합격 *(합격선 2차 출처 기준)* / 비감독 | 시험만 $325, 자율학습+시험 $500 | 24개월 | 없음 |
| **FOCE** (Engineer) | 인프라 구축·운영 엔지니어 | 객관식 50문항 / 60분 / 75% *(추정)* / 비감독 | 시험만 $325, 번들 $500 | 24개월 | 없음(권장 FOCP) |
| **FinOps for AI** (AI Value) | AI/GPU·모델 비용 관리 | 단계형 학습 후 인증 *(추정)* | 약 $500 | 24개월 *(추정)* | 권장 FOCP/FOCE |
| **Technology Value** | SaaS·라이선스 비용 | 단계형 학습 후 인증 *(추정)* | 약 $500 *(추정)* | 24개월 *(추정)* | 권장 FOCP/FOCE |
| **FOCUS Analyst** | FOCUS 데이터 정규화·분석 | 인증 시험 | 시험만 $325, 번들 $600 *(추정)* | 24개월 *(추정)* | 없음 |
| **FCP** (Professional) | 고급 실무자(최상위) | 객관식 100문항 / 120분 / 75% + 라이브 세션·기여 프로젝트 | 번들 $1,999 *(공식 공지 기준, 변동 가능)* | 36개월 | FOCP/FOCE + 실무 6개월 + FOCUS·Tech·AI Value 인증 + 커뮤니티 기여 *(공식 공지 기준)* |

- 공식: [finops.org/training-certification](https://www.finops.org/training-certification/) · [learn.finops.org](https://learn.finops.org/) ·  
  [Linux Foundation 인증 페이지](https://training.linuxfoundation.org/certification/certified-finops/)
- **검증 한계**: `learn.finops.org` 개별 인증 상세 페이지가 자동 접근을 차단(HTTP 403)하여, AI Value·Technology Value·FOCUS Analyst의  
  시험 문항수·합격선·갱신 주기 일부는 2차 출처 기반 *(추정)* 표기. 최종 취득 전 공식 페이지 직접 확인 권장.

### 조직 인증 (강사 개인 취득 대상 아님 — 참고)

`FinOps Certified Service Provider`(컨설팅 기업), `FinOps Certified Platform`(도구 벤더),  
`FinOps Certified Training Provider`(교육 기관)는 모두 **기업/제품 단위 조직 인증**으로 개인 강사 자격으로는 부적합.  
출처: [finops.org/certification-for-organizations](https://www.finops.org/certification-for-organizations/)

## 4. Microsoft Azure 기반 교육·인증

### 4-1. Microsoft 공식 FinOps 자격증 — **존재하지 않음**

- `learn.microsoft.com` 인증 카탈로그에 "FinOps" 명칭의 Certified/Applied Skills 자격 **부재**.
- 개인 FinOps 자격증의 실제 발급처는 **FinOps Foundation**(MS 아님).
- **정직성 유의**: 강의 자료에서 "Microsoft FinOps 자격증" 표현 사용 금지.  
  "Microsoft Learn **수료 배지**" 또는 "FinOps Foundation **자격증**"으로 정확히 구분 표기.

### 4-2. Microsoft Learn FinOps 학습 경로 (무료 수료 배지)

| 모듈 | 레벨 | 구성 | 수료 증빙 |
|---|---|---|---|
| **Get started with FinOps** | Beginner | 9 Units (FinOps 정의·원칙·페르소나·단계·성숙도·도메인/역량) | 모듈 완료 시 **수료 배지(Badge)** |
| **Adopt FinOps on Azure** | Intermediate | 8 Units (사용량/비용 이해·가치 정량화·최적화·실무 관리·Iteration 실습) | 모듈 완료 시 **수료 배지(Badge)** |

- 두 모듈 모두 콘텐츠 출처를 **FinOps Foundation Framework**로 명시(Attribution). MS Learn은 프레임워크를 Azure 실무에 매핑한 것.
- 배지 성격: **시험 기반 자격증이 아닌 "수료 배지"**. 모듈 말미 Assessment는 지식 점검 수준으로 공인 자격 아님.
- 공식: [Get started with FinOps](https://learn.microsoft.com/en-us/training/modules/get-started-with-finops/) ·  
  [Adopt FinOps on Azure](https://learn.microsoft.com/en-us/training/modules/adopt-finops-on-azure/)

### 4-3. Azure 인증 — FinOps 강사 보완재 (비용은 거버넌스 영역에 통합)

| 자격 | 비용·거버넌스 범위 | 강사 보완재 의미 |
|---|---|---|
| **AZ-104** (Azure Administrator Associate) | "Manage identities and governance"(20–25%)에 Cost Management·예산·태그·정책 포함 | Inform 단계 실습(Cost Management·태깅) **실조작 수준** 증명 |
| **AZ-305** (Azure Solutions Architect Expert) | 거버넌스·모니터링 설계에 비용 최적화 설계 포함 | Right-sizing·약정(RI/SP) **설계 관점** 권위 보강 |

- 두 자격 모두 비용이 **독립 시험 도메인이 아니라 거버넌스 영역에 통합**됨. FinOps "전문" 증명으로는 부족하나 Azure 기술 신뢰도 보완재로 유효.
- 공식: [AZ-104 가이드](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-104) ·  
  [AZ-305 가이드](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-305)

### 4-4. FinOps Toolkit — 실습 콘텐츠 출처 (자격증 아님, 공신력 최상위)

| 자산 | 성격 | 강의 가치 |
|---|---|---|
| **FinOps Toolkit** | MS 오픈소스(GitHub `microsoft/finops-toolkit`), 월간 릴리스 | Bicep 모듈·Power BI 리포트·FinOps Hubs **실습 산출물 직접 제공** |
| **Power BI Reports** | Cost summary·Rate/Workload optimization·Policy 리포트 | 대시보드 실습 템플릿 |
| **FinOps 문서 허브** | `learn.microsoft.com` 공식 가이드 | 프레임워크→Azure 매핑 1차 출처 |

- 자격증은 아니나 1차 출처 공식 문서·오픈소스로 **강의 실습·인용 출처로서 공신력 최상위**.
- 공식: [FinOps Toolkit overview](https://learn.microsoft.com/en-us/cloud-computing/finops/toolkit/finops-toolkit-overview) ·  
  [FinOps documentation](https://learn.microsoft.com/en-us/cloud-computing/finops/)

### 4-5. MS의 FinOps Foundation 인증 보유 현황

- **FinOps Certified Service Provider**(조직 인증) **보유** — 2025-06-12 Azure 블로그 발표.  
  출처: [Microsoft is now a FinOps Certified Service Provider](https://azure.microsoft.com/en-us/blog/microsoft-is-now-a-finops-certified-service-provider/)
- **정직성 유의**: MS가 보유한 것은 **서비스 제공사(조직) 인증**이며, 제품(Cost Management)의 `FinOps Certified Platform` 인증은  
  공개 페이지에서 미확인. 강의에서 "Cost Management = FinOps Certified Platform" 단정 금지.

## 5. 커리큘럼 정합성 — 자격증/교육이 커버하는 모듈 매핑

| 커리큘럼 모듈 | 직접 대응 자격증/교육 |
|---|---|
| M1 WHY·COVERS·성숙도 | FOCP, MS Learn `Get started with FinOps` |
| M2 Inform (태깅·가시화·이상탐지·FOCUS) | FOCP, **AZ-104**(태깅·Cost Mgmt), MS Learn `Adopt FinOps on Azure`, FinOps Toolkit Power BI |
| M3·M4 Optimize (스케일링·Right-sizing·Tiering) | FOCP, **AZ-305**(설계), MS Learn `Adopt FinOps on Azure` |
| M5 Optimize (RI/SP/Spot 약정) | FOCP, AZ-305 |
| M6 Operate (단위경제 KPI·협업) | FOCP, MS Learn 2종 |

→ **FOCP 1종으로 전 모듈 포괄**, AZ-104/AZ-305가 M2~M5 Azure 실습의 기술 권위 보강.

## 6. 최종 권고

1. **즉시 (이번 강의 전)**: Microsoft Learn `Get started with FinOps` + `Adopt FinOps on Azure` 배지 취득(무료) →  
   Azure 특화 수료 증빙 확보 및 강의 실습 흐름과 직접 정합.
2. **단기 (1~2개월)**: **FOCP** 취득 → FinOps 강사의 1차 공신력 자격 확보.  
   취득 후 **24개월 주기 갱신**(재인증) 필요 — 강사 자격 라이프사이클 관리 유의.
3. **중기 (선택)**: KT 1일 과정은 실습 비중이 크므로 **AZ-104 우선 권장**.  
   설계 비중 강화 시 **AZ-305** 선택 → Azure 비용 실무/설계 신뢰도 보강.
4. **실습 콘텐츠**: **FinOps Toolkit / Power BI Reports**를 1차 출처 실습·인용 자료로 활용.
